Search and filters

Syntax Examples:

  • host:ubuntu - Filter by hostname
  • user:root - Filter by username
  • severity:5 - Filter by severity level
  • type:LOGIN_FAIL - Filter by event type
  • ip:192.168.1.1 - Filter by source IP

Operators:

  • AND - Combine filters (default)
  • OR - Match any filter
  • -field:value - Negate (exclude)

Complex Queries:

  • host:ubuntu AND severity:4
  • user:root OR user:admin
  • -user:guest (exclude guest)
  • \"failed login attempt\" (search raw message)

Field Aliases:

  • host/hostname, user/username, ip/source_ip, os/os_type
  • type/eventtype/event_type
  • message/msg/raw_message

ORGANIZATIONS

An organization is a workspace. Sites group the endpoints inside it. Create the organization, then move an endpoint when it should live somewhere else. Agent keys cannot see or change another organization.

EDIT ORGANIZATION
MOVE ENDPOINT

Stored events for this endpoint move with it. The next events from its agent land in the destination.

ACTION1

Sync reads managed endpoints, online status, missing updates, vulnerabilities, groups, packages, report names, and console users. It does not install software, edit groups, or start remediations. Installing the Heimdall agent is a separate one-time script on the checked endpoints. Critical findings stay below the Telegram threshold unless you opt in before a sync. Removing an endpoint deletes it in Action1.

A client id works only in the region where it was created. North America 2 is app.na-2.action1.com.

Off by default. Critical missing updates and critical vulnerabilities stay at severity 3. Turn this on before a sync if those new findings should page. Findings already stored keep their severity.

LINK ORGANIZATIONS

Each Action1 organization syncs into one Heimdall organization, on a site named Action1. Test the connection to load the Action1 list.

SYNC
Endpoints

Check Windows, Mac, or Linux endpoints, then install the Heimdall agent. Action1 runs that installer once. Offline computers are retried for 24 hours, and the computer stays up. The Linux role is written to every checked Linux endpoint. Windows and Mac use their own installers. macOS needs Python 3.10 or newer, and Full Disk Access is turned on after the install.

Leave the hub URL blank to use this server's address on port 8010, or SIEM_PUBLIC_URL when that is set. Endpoints download the installer from that address.

DOCKER SERVERS

Add a docker server to the organization you are viewing. Heimdall connects with SSH and reads cve-check.log and update.log, plus cve-check.log.1 and update.log.1 after those rotated copies appear. It does not read .cache. The first copy of a log is history and does not page Telegram. A later scan with new fixable advisories pages once. A new stack-update failure pages. A missing update.log is normal until the first update runs.

Install this public key for the SSH user on the docker server. The private key stays on the Heimdall hub.
